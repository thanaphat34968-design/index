📐 รวมสูตร Calculus 1

สูตรพื้นฐานที่ควรจำ

Derivative

d/dx(c) = 0
d/dx(xⁿ) = nxⁿ⁻¹
d/dx(sin x) = cos x
d/dx(cos x) = -sin x
d/dx(eˣ) = eˣ
d/dx(ln x) = 1/x

Derivative Rules

(fg)' = f'g + fg'
(f/g)' = (gf' - fg')/g²
Chain Rule
f(g(x))' = f'(g(x))g'(x)

Integral

∫xⁿdx = xⁿ⁺¹/(n+1)+C
∫1/x dx = ln|x|+C
∫eˣdx = eˣ+C
∫cos x dx = sin x+C
∫sin x dx = -cos x+C

Trigonometry

sin²x + cos²x = 1
1 + tan²x = sec²x
1 + cot²x = csc²x

📝 ตัวอย่างโจทย์

ตัวอย่างพร้อมวิธีทำ

ข้อ 1: จงหาอนุพันธ์ของ f(x) = x³ + 2x²

ใช้ Power Rule

d/dx(x³) = 3x²

d/dx(2x²) = 4x

ดังนั้น f'(x) = 3x² + 4x

ข้อ 2: จงหา ∫4x³dx

ใช้สูตร Power Rule สำหรับ Integral

∫4x³dx = x⁴ + C

ข้อ 3: จงหา lim(x→2)(x²+3)

แทนค่า x = 2

2² + 3 = 7

คำตอบ = 7
